# Каталог товаров

## Описание

Приложение для управления каталогом товаров, оформления и редактирования заказов.

## Технологии

- Python 3.11
- Tkinter (GUI)
- SQLite (БД)
- Pillow (изображения)

## Установка

\`\`\`bash
git clone <repo>
cd up02-project-aliev
python -m venv venv
venv\Scripts\Activate.ps1
pip install -r requirements.txt
python main_catalog.py
\`\`\`

## Роли

| Роль | Права |
|------|-------|
| Клиент | Каталог, оформление заказа |
| Менеджер | + список заказов, состав |
| Администратор | + редактирование, удаление |
